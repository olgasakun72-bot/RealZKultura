+---НАЗНАЧЕНИЕ РАЗДЕЛА---+ arsenal/tools :: reference database

Справочник утилит, которыми реально пользуются при разборе открытых источников и аудите собственного периметра. По каждой записи: тип интерфейса, порог входа, принцип работы и базовая команда, с которой начинают.

Команды даны на документационных адресах RFC 5737 (192.0.2.0/24) и на условных доменах. Подставьте свои значения — и только те, на которые у вас есть письменное разрешение.

[ ПОРЯДОК РАБОТЫ ] // ЧТО ЗАПУСКАТЬ ПЕРВЫМ

+---OSINT-КОНТУР---+
# типовой порядок, от дешёвого к дорогому

01  exiftool -a -u -G1 file      # метаданные: автор, ПО, часовой пояс
02  strings -n 8 file | grep -iE "user|home"   # логины и пути
03  sherlock nickname            # где ещё встречается ник
04  maigret nickname -a --html   # глубже + извлечение полей профиля
05  whatsmyname.app/?q=nickname  # ручная проверка гипотез
06  web.archive.org/web/*/URL    # удалённые профили
07  holehe mail@example.com      # где зарегистрирована почта
08  suncalc.org + геометрия тени # хронолокация кадра

# правило: шаг 03-05 даёт гипотезы, а вывод делают только
# два независимых источника. Один ник на двух площадках — не личность.
+---АУДИТ-КОНТУР---+
# только при письменном разрешении владельца

01  crt.sh/?q=%.example.com      # поддомены из логов сертификатов
02  testssl.sh --full example.com # TLS: версии, шифры, HSTS
03  nmap -sV -sC 192.0.2.0/24  # сервисы и версии
04  nikto -h https://192.0.2.10  # типовые ошибки веб-сервера
05  zap.sh -cmd -quickurl URL     # быстрый прогон приложения
06  tshark -i eth0 -w cap.pcap   # захват для разбора в wireshark
07  gitleaks detect --source .   # секреты в собственной истории
08  trufflehog filesystem ./     # живые ли найденные ключи

# порядок не случаен: сначала пассивно и дёшево,
# активное сканирование — после согласования окна и стоп-слова.
[ЧТО НЕ ВОШЛО В АРСЕНАЛ НАМЕРЕННО] Утилиты целевой слежки, автоматизированного перебора чужих учётных записей, пробива по слитым базам персональных данных, генерации вредоносного кода и клонирования банковских интерфейсов. Их существование обсуждается в теоретических разборах ядра 0xBASE, но в рабочий справочник они не включены: у таких инструментов нет законного бытового применения.
